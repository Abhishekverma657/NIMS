# NIMS Super-Speciality Hospital Website

Official modern web application for **NIMS Hospital Jaipur** (National Institute of Medical Sciences & Research).

## Features
- **Modern Responsive Design**: Fully responsive across mobile, tablet, and desktop screens with zero clipping.
- **Specialities & Clinical Departments**: 30+ comprehensive departments with doctors, procedures, and facilities.
- **Doctor Directory & Booking**: Quick OPD appointment scheduling drawer with real-time feedback.
- **Interactive Photo Gallery**: Category filters and smooth full-screen image lightbox modal.
- **24x7 Emergency Helpline**: Dedicated rapid response CTA and emergency care information.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
